# 🎫 Python IT Help Desk Ticket Analyzer
A Python project that analyzes IT support tickets, identifies trends, and generates help desk performance reports.


## Project Overview

This project analyzes IT support tickets using Python to identify trends, common issues, and support performance metrics.

The goal is to demonstrate how data analysis can help IT teams improve troubleshooting processes and reduce repeated issues.

## Features

- Reads support ticket data from a CSV file
- Calculates average ticket resolution time
- Identifies the most common support issue
- Generates an IT support report

## Technologies Used

- Python
- CSV Data Processing
- File Handling
- Data Analysis
- Problem Solving
